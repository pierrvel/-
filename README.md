# 🔥 중간고사 직보 맞춤형 초정밀 마스터 대시보드 플래너

중간고사 대비 직전 보강 및 타임테이블을 완벽하게 관리하는 초정밀 반응형 스터디 플래너입니다.

## ✨ 주요 기능
- **단일 소스 상태 관리**: 체크 상태 및 진행률 오차 없는 100% 실시간 연동
- **일자별 & 과목별 달성률**: 전체 진행률뿐만 아니라 당일 목표 달성률 게이지 제공
- **스마트폰 & 태블릿(아이패드) 최적화**: 
  - 📊 과목별 모아보기
  - ⏰ 일자별 타임테이블
  - 💻📱 듀얼 분할 뷰 (태블릿/PC에서 좌측 일정 + 우측 과목 카드 동시 표시)
- **기기 간 실시간 동기화 (Multi-Device Sync)**:
  - 폰 ↔ 패드 ↔ PC 어디서든 PIN 코드 하나로 5초마다 자동 실시간 동기화
  - 카메라로 비추기만 하면 즉시 열리는 QR 코드 스캔 기능
- **학습 편의성**:
  - 🌙 야간 집중 다크 모드 / ☀️ 라이트 모드
  - 📅 D-Day 카운트다운 뱃지
  - 🎉 100% 완주 축하 폭죽 효과

## 🚀 배포 방법

### 1. Vercel 배포 (가장 추천)
1. GitHub에 이 레포지토리를 푸시합니다.
2. [Vercel](https://vercel.com)에 로그인 후 **Add New Project** 클릭
3. 해당 GitHub 레포지토리를 선택하고 **Deploy** 버튼 클릭!
4. 생성된 고유 주소(`https://xxx.vercel.app`)로 폰과 아이패드에서 사용하세요.

### 2. GitHub Pages 배포
1. GitHub 레포지토리의 **Settings ➔ Pages**로 이동합니다.
2. Build and deployment의 Source를 **Deploy from a branch**로 선택합니다.
3. Branch를 `main` (또는 `master`), 폴더를 `/ (root)`로 선택하고 **Save**합니다.
4. 잠시 후 `https://<깃헙아이디>.github.io/<저장소이름>`으로 웹사이트가 열립니다.
